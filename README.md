# Fnessus

![SPONGE](https://user-images.githubusercontent.com/119784145/206905458-15c80647-fa3a-4a5b-812c-e03e3f1977e2.jpg)

F*** Nessus  is a fast, Lightweight service misconfiguration scanner for ctfs, king of the hill or other small scale projects

# Installation

```shell
git clone https://github.com/c1nn3r/fnessus.git
cd ./fnessus
pip3 install -r requirements.txt
python3 fnessus.py --help
```
